## Engineering Governance

GitHub is used as the controlled engineering evidence environment for CivicConnect.

Substantive work is:

- represented through meaningful issues/tasks;
- completed on dedicated task branches;
- integrated into `main` through Pull Requests;
- reviewed by both non-author team members;
- merged only after required approvals and review conversations are resolved.

The protected `main` branch represents the controlled project state.
